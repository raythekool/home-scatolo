# Prompt di riconoscimento — versionati

## v1 — Riconoscimento oggetti generico

```
Analizza l'immagine e restituisci un elenco JSON degli oggetti visibili.
Per ciascun oggetto includi: "nome", "categoria", "descrizione_breve".
Rispondi solo con JSON valido, nessun testo aggiuntivo.
```

Aggiorna questo file ogni volta che modifichi il prompt di produzione, mantenendo lo storico delle versioni precedenti per confronto.
